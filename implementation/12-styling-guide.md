# Styling Guide (Neo-Brutalism)

## Design Tokens

### Colors
- **Background**: `#FFFFFF`
- **Surface**: `#EEEEEE`
- **Primary**: `#FFDD00` (Neo-Yellow)
- **Secondary**: `#FF00FF` (Neo-Pink)
- **Accent**: `#00FFFF` (Neo-Cyan)
- **Text**: `#000000` (Deep Black)
- **Stroke**: `#000000` (Bold Outlines)

### Typography
- **Headings**: `Inter-Bold` or `Bebas Neue` (Caps-heavy).
- **Body**: `Roboto` or `Space Grotesk`.
- **Monospace**: `Fira Code` (for agent logs).

### Components
- **Buttons**:
  - `border: 4px solid black`
  - `box-shadow: 6px 6px 0px 0px #000`
  - `transition: transform 0.1s`
  - `active: transform translate(2px, 2px), box-shadow 4px 4px 0px 0px #000`

### Spacing & Grid
- **Hard Grids**: No soft transitions; use sharp layout breaks.
- **Gutters**: Large gaps (24px-32px) between cards.
