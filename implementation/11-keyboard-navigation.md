# Keyboard Navigation & Accessibility

## Accessibility Targets
- **WCAG 2.1 AA Compliance**: Ensuring the platform is usable for all content creators.
- **Aria-Labels**: Descriptive labels for complex UI components (Progress swarms, agent terminals).

## Keyboard Shortcuts
- `CMD/CTRL + G`: Open "New Generation" modal.
- `CMD/CTRL + B`: Toggle Batch Mode.
- `CMD/CTRL + F`: Focus Search Bar.
- `Esc`: Close any active modal.
- `Arrow Keys`: Navigate Kanban cards or Calendar dates.

## Focus Management
- Log terminal automatically auto-scrolls unless manually interrupted.
- Focus traps for modals (Config Loader setup).
- High-visibility focus rings (Neo-yellow, 4px solid).
